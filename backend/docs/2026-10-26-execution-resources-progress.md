## 用户修订：Module 只维护参数说明

用户明确修正：Module 资源用于提前维护快速执行的参数说明，采用自主添加的 key-value 行，不需要默认模块参数、extra_vars、高级配置，也不要自动显示内置「模块参数参考」。以上修订替代前文 Module 原生默认参数编辑方案，Playbook 不变。

- Module 新建、版本编辑与详情均按此简化；参数 Key 为名称，Value 为说明，提供添加、删除、重名和缺失内容校验。
- 参数说明随资源版本保存和发布；快速执行仅读取所选版本的用户配置，不对资源库自动回退内置说明。在线自定义模块原有帮助保持兼容。
- 使用独立说明元数据，说明不进入实际参数或变量校验；新说明版本清除隐藏的历史默认参数及高级配置，实际参数在执行时填写。
- 已发布的旧版本保持不变；基于旧版本创建并发布新草稿后使用新语义。原有 key=value、JSON 与自由命令执行协议保持兼容。
- 已删除不再使用的默认参数编辑 helper 及其专属旧表单测试，增加说明往返、后端校验与实际 Vue 表单渲染回归。
- 无新增数据库迁移。
