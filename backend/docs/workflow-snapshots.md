# T12 发布与运行协议

唯一编辑模式为 `graph`，节点词汇及无 Django 依赖的图校验在 `common/workflow`。旧 steps/bpmn、XML 字段及运行时线性图补齐已删除。图必须有一个开始节点、至少一个结束节点，无环、无悬空边，业务节点超时为正整数。

发布事务锁定版本，重新读取节点/边，冻结命令正文、参数、全局变量、输入定义及 API/Jenkins/通知配置，计算完整快照摘要。发布及归档版本的模型保存和 queryset 更新拒绝内容变化，允许发布转归档。API 发布元数据只读；节点编辑 API 校验草稿状态。原始 SQL 不属于模型层保护范围。

运行调度、命令执行及通用节点执行使用运行自己的快照。删除工作流模板不会丢失执行定义。凭据不复制到资源快照；执行时检查引用是否可用。API/Jenkins 的地址或身份绑定变化后拒绝使用旧快照，凭据轮换不会固化旧秘密。资源正文内已知明文认证值拒绝发布，使用加密凭据字段或运行秘密输入。

条件只允许数据取值、比较和布尔表达式，禁止函数调用、过滤器、私有属性及算术放大。正常出口按条件选择，无匹配时选择唯一默认出口。未选择路径跳过，汇合等待所有入边作出决定及已选路径完成。

T13 继续将系统快捷模板、手工运行和重试创建完全纳入发布/创建协议，删除旧顺序执行函数；本阶段不提供旧数据库升级和图转换。
