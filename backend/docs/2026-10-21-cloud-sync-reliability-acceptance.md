# 多云资产同步可靠性：部署与验收

## 交付范围

- SDK/API 只读采集，保留手动读取、预览、选择和确认流程。不接入 Terraform。
- 来源资产按“来源账号 ID + 实例 ID”建立数据库唯一身份摘要；没有来源实例 ID 的人工资产按“主机名 + IP”去重。不同云账号中的同名、同内网 IP 资产可以共存。
- 重复 Celery 投递只认领一次；同账号写入通过账号行锁串行化；旧观测不覆盖新观测；无变化及过期观测计为跳过，不计更新或失败。
- 任一区域读取失败或云端返回重复实例 ID，本次读取整体失败；不将已读取区域伪装成完整结果。入库失败和读取失败分别在记录中呈现，部分入库失败明确标记为部分成功。
- 未采集字段不覆盖已有值；外网 IP 显式空字符串可清空；磁盘 0 是真实值；布尔、小数、负数不作为有效整数规格接收。未返回主机不会自动删除、停用或退役。
- 云实例运行状态、人工资产状态、连接测试结果相互独立；列表默认保持原结构，云运行状态和资产来源可从列设置开启，也可通过状态/主机名提示查看。
- 周期同步默认关闭。开启者需要同步权限，每次执行重新验证开启者有效性和权限；同步间隔 5–10080 分钟。停止账号、关闭周期同步、权限失效均不会继续写入。
- 周期同步按启用时授权自动导入配置范围内新增与变化资产；不逐次弹窗。手动运行仍需确认。
- 失败或部分失败可发送通知，复用已有通知记录、模板快照和失败重试。管理员可在通知发送记录查看同步告警。通知模板新增“资产同步失败”变量说明/预览/测试场景。
- 同步记录支持查看触发方式、范围、观测时间与字段前后值。历史记录没有真实观测时间时保留为空，不伪造升级时间。
- 云账号展示当前采集字段能力及范围说明；五种平台并不承诺字段完全一致，私有云 Guest/Agent 依赖继续生效。

## 部署

1. 备份数据库，暂时停止资产写入入口、Celery Beat 和旧 Worker，等待正在执行的同步结束。避免旧代码继续写入缺少身份摘要的资产。
2. 在后端虚拟环境执行 `poetry run python manage.py migrate`。
3. 本轮新增迁移：`automation/0009_notificationrecord_context_and_more.py`、`cmdb/0013_assethost_cloud_state_assethost_last_observed_at_and_more.py`、`cmdb/0014_alter_assethost_unique_together_and_more.py`。
4. 若 0013 提示重复来源身份，会在该迁移进行 DDL 前中止，并输出冲突资产 ID。核对云实例、凭据、分组及标签归属后由管理员处理，再执行迁移；不会自动合并或删除资产。0014 对人工资产无效 IP 也先检查后中止。
5. 部署新前端构建，启动新 API、监听 `task` 队列的新 Worker 和 Beat。必须重启 Worker，不能只重启 API。
6. 所有账号默认关闭周期同步。按账号开启，不批量自动启用。
7. MySQL 等生产数据库需先在预发布库演练迁移；自动测试使用隔离 SQLite。来源身份依赖平台 ORM 保存路径生成，直接 SQL/bulk_create 写入需自行提供正确身份或使用同步服务。

存量重复身份的只读查询参考（不要据此直接删除）：

```sql
SELECT asset_source_id, TRIM(source_id) AS instance_id, COUNT(*) AS records
FROM cmdb_asset_host
WHERE asset_source_id IS NOT NULL AND TRIM(source_id) <> ''
GROUP BY asset_source_id, TRIM(source_id)
HAVING COUNT(*) > 1;
```

回退前需检查新版本已允许的跨账号同名同 IP 资产；不要直接恢复旧的全局主机名/IP 唯一约束。

## 手动验收

1. **默认策略**：进入资产接入，现有账号卡片显示“周期同步：未开启”，编辑账号的“同步策略与通知”折叠区也关闭；保存不应触发自动导入。
2. **正常手动同步**：读取云主机，选择一台同步。记录标为“手动同步”；展开后能看到配置区域、读取数量、所选数量、真实采集时间、创建或字段变化。资产状态仍按人工配置维护。
3. **重复导入**：不改云主机，再次读取。主机应显示未变化；周期运行没有变化时更新数为 0，记入跳过，不能重复创建。
4. **跨账号相同地址**：在两套测试云环境中使用同名、同内网地址主机，分别导入。来源不同的两条记录可共存；主机名提示及列设置中的资产来源能区分账号。再次读取分别命中各自实例。
5. **人工去重**：手动新增已存在的人工主机名/IP 组合，表单应返回明确错误，不能新增重复记录。
6. **字段保护**：给已有云主机设置凭据、团队、分组和标签，再同步云端规格；人工配置保持不变。释放云端外网地址后重新读取并确认，外网地址被清空。
7. **状态区分**：测试云主机关机后同步，云运行状态显示已关机，但人工在用/停用/退役状态保持原值。连接测试单独给出结果。不要在生产主机执行此项。
8. **区域失败**：使用测试账号配置一个没有访问权限的区域。读取应指出失败区域，不显示为成功完整读取，不修改已经存在的资产。
9. **周期同步**：用具备同步权限的用户编辑测试账号，开启周期同步并设 5 分钟。下一次 Beat 检查后应生成“周期触发”记录，随后按间隔运行。首次运行将导入该账号当前配置范围内所有有效新增和变化主机，开启前务必核对范围。
10. **避免重叠**：已有排队或运行中的同步时，不再为该账号安排第二个周期任务；手动提交也明确提示等待。超过 30 分钟无进展的任务标记失败，旧 Worker 不再继续后续写入；慢速私有云需关注该时间边界。
11. **撤销授权**：移除周期同步开启者的同步权限，下一次运行应在读取前失败并提示重新授权；不能绕过权限自动导入。
12. **关闭周期**：关闭开关或停用账号，后续不生成新的周期任务。已排队任务执行时也会检查账号配置变化或停用状态。
13. **失败通知**：先在通知模板选择“资产同步失败”场景，验证下方示例模板的预览和测试发送，再给云账号配置该模板。制造测试区域权限失败，应收到通知，并在管理员通知发送记录中看到结果。同一同步记录不会因重复投递创建多条告警记录。
14. **通知失败**：用测试 Webhook 故意返回错误，应保留失败发送记录并按现有告警规则重试；修改或删除模板后不会悄悄使用新模板正文替换已经冻结的失败告警。

通知示例：

```text
标题：{{ title }}
正文：账号 {{ sync.sourceName }} 同步失败。
同步编号：{{ sync.id }}
触发方式：{{ sync.trigger }}
原因：{{ sync.errorMessage }}
```
