# V2 回滚边界

尚未执行上线或回滚。任何入口切换都需要明确授权。

WebSocket 故障时前端通过新协议 REST 游标继续补拉；该降级不需要恢复旧日志服务。先确认事件持久化和 REST 可用，再处理 Redis、Origin、票据或 Channel Layer 故障。

整体回退必须成套恢复前端、API、ASGI、调度进程、Worker、配置、数据库及队列。先停止新运行接入，记录在途运行和取消请求；未确认 Worker 退出的命令不能直接重跑，否则可能重复产生外部副作用。

切换前保留新库和归档的备份，不删除新系统产生的数据。旧代码不能连接 V2 新迁移库；V2 数据不会自动反向迁移。若旧环境已被授权销毁，只能从匹配备份重建，Git 分支不能恢复数据库。

回退后确认消费者只监听所属环境队列，检查权限、读取、事件序列、归档和已知在途运行。记录切换时间、版本、数据截止点及未确认执行结果。
