# 监控接入第二阶段：部署与验收

## 本批新增

1. Consul 服务目录：按数据中心、服务查询 Catalog/Health，跨节点实例分页展示节点、地址、端口、健康状态和标签。目录始终只读，即使实例 Meta 声称由平台管理，也不会转为当前 Agent 的可写实例。
2. 从 CMDB 批量接入：选择连接及主机 → 配置 Exporter 端口、地址来源、可选定时同步 → 读取并预览 → 确认接入。每次最多 200 台。
3. 目标级定时同步：0 为关闭，支持 1–10080 分钟；每分钟由 Beat 扫描到期目标并通过 Worker 注册。
4. 可选跟随关联主机的内网/外网 IP；同步记录区分手动、批量接入、定时同步。

不自动安装 Exporter，不自动把新加入 CMDB 的主机纳管，不自动删除或注销停用、失联的资产。动态分组纳管仍属后续阶段。

## 升级

先备份数据库，在部署环境 `backend/` 执行：

```text
poetry run python manage.py migrate
poetry run python manage.py init_system_settings
```

同批部署前端、API、Worker、Beat。新增迁移为 monitoring `0004_monitoringtarget_address_source_and_more`，旧目标的自动同步默认关闭，原同步记录默认标记为手动。

普通角色需重新分配“从资产接入”按钮权限；权限依赖包含主机选择器所需的主机/分组读取以及注册权限。Catalog 查询权限随 Consul 菜单授权。重新登录刷新按钮和菜单。

保持各 API 实例 `SECRET_KEY` 一致：批量预览证明使用 Django 签名，绑定当前用户与输入及资产快照，十分钟过期。更换账号、修改端口/地址来源、资产 IP/状态变化、已有目标变化、签名过期或密钥轮换后都需要重新预览。

## 批量接入行为

- 仅创建主机 Exporter 目标。批次内按 IP 去重；已有同连接的主机目标或相同地址端口目标会跳过，保留其配置。
- 停用资产、缺少指定 IP 或不允许的地址会标为无效，不自动回退其他网络地址。
- 确认后原子创建目标与注册记录，再投递 Worker 任务。页面创建成功不表示 Consul 注册成功，需查看同步状态和记录。投递失败保留目标和明确错误，修复队列后可在目标页重新同步。
- 新目标 Meta 保存接入时的资产 ID、名称、环境、地域；这些是接入快照，不自动跟随所有资产字段更新。
- Node Exporter 默认示例端口为 9100；Windows Exporter 等不同端口应分别接入。地址必须可被 Prometheus 和所需 Consul 检查访问。

## 定时同步授权与安全

启用或更改会影响注册内容的自动同步配置时，需要同步权限，并绑定当前账号作为执行账号。仅有目标编辑权限不能借用旧账号把配置自动写入 Consul。

调度和 Worker 执行时均复核账号有效性及当前权限。跟随资产 IP 还需要关联主机读取权限；权限失效会暂停定时同步并留下失败记录。重新授权后由有权限的账号编辑并启用。

主机删除、停用、缺少所选 IP 或在入队后 IP 发生变化时，本次自动执行停止，原注册保留。下一轮按当前资产地址重试；不会在权限/资产异常时自动注销。

跟随地址仅在自动同步执行时更新 Exporter 地址，不更新其他目标配置。关闭定时同步但保留跟随选项不会持续更新 IP。

手动注销会同时把定时同步间隔设为 0，避免刚注销的实例被下一轮注册回来。重新启用需要显式编辑配置。

## 手动验收

1. 进入“Consul 管理 → 服务目录”，选择另一个数据中心和服务，确认实例按节点区分、节点 critical 会覆盖服务 passing，且无注册/注销按钮。
2. 快速切换数据中心、服务和页码，确认旧响应不会覆盖当前选择；查询失败不显示为成功的空清单。
3. 从资产接入 2–3 台主机，预览确认只有有效地址会新增；已有目标显示跳过。确认后在目标页查看注册记录来源为“批量接入”。
4. 预览后在另一页面修改资产 IP，再确认，应该要求重新预览；重复点击确认不能重复创建目标。
5. 新增目标配置一分钟定时同步，检查记录来源为“定时同步”，不存在同一目标的并发重复任务。
6. 启用跟随外网 IP，变更 CMDB 外网 IP，观察下一次更新；清空外网 IP 后应失败并保留旧服务，不回退内网 IP。
7. 撤销执行账号的同步权限或停用账号，确认任务停止外部写入并有失败记录。只有编辑权限的账号修改自动目标的端口、Meta 等字段应被拒绝。
8. 手动注销自动目标，确认定时同步关闭、后续不再自动恢复注册。

本批验证使用隔离数据库和模拟 Consul；部署数据库升级及真实 Consul/Prometheus 联调需在测试环境完成。
