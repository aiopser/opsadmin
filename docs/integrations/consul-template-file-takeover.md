# Consul Template 现有文件接管

平台整文件管理 config 目录的 HCL 与 template 目录的 CTMPL，不拆解 HCL 的 template 块，也不改写 KV 表达式、应用重载命令或相对路径。

## 页面操作

1. 新增或编辑记录，选择启用的 Linux SSH 主机，填写 `.hcl` 或 `.ctmpl` 绝对路径。
2. “从主机读取”由执行节点读取文件并填入草稿。替换不同草稿前确认；空文件正常读取，不存在、权限不足、编码或网络错误不清空草稿。读取期间新增的编辑不被旧响应覆盖。
3. “比较远端差异”只比较，不保存或重载；“保存草稿”只写平台记录。
4. 列表“比较并下发”重新读取远端，确认差异后排队下发。绑定操作者、主机、路径、模板修订和远端 SHA256，过期或文件变化后必须重新比较。最终校验在目标机完成。

HCL 与 CTMPL 分别接管，本轮不包含批量扫描目录或多文件联合提交。HCL 的 source 相对路径需与现有进程工作目录保持一致。

## 权限与运行

- 新增“读取远端文件”按钮权限，结果仅限发起人查看。提交、执行、落库及取回正文时复核账号与相应的主机、凭据、执行池授权。
- 读取不要求高危执行权限。下发可能执行配置中的命令，按既有高危权限校验；非管理员需显式授予 `automation.command:execute_high_risk`，不会隐式赋给读取角色。
- 外层重载只允许针对 consul-template 的 reload/restart 或 HUP，不允许控制其他服务；HCL 内部 command 原样保留。
- 读取限 UTF-8 普通文件、256 KiB，拒绝直接符号链接。主机需 python3；下发依赖 GNU coreutils。使用现有 Ansible Runner、SSH 凭据、执行池及网关，Web 不直接执行 Ansible。

## 可靠性

- 读取缓存正文加密，接口禁止缓存，10分钟后失效并清除正文；一天后删除临时记录。保存草稿使用平台已有配置记录。领域审计不含读取正文。
- 每账号最多3个有效读取任务，支持队列重投、超时和重复任务认领保护。
- 同一模板的活动下发互斥，远端文件锁避免平台同时写同一文件。保留原文件属主和权限，替换前再次校验。重载失败恢复文件并尝试恢复服务；恢复失败保留备份并输出明确日志。
- 新文件默认0600，执行用户必须满足运行服务读取权限。平台不执行候选配置的渲染校验；实际 reload/restart 行为应在测试服务单元中验收。外部编辑程序不遵守同一锁时，仍需约定维护窗口。
- 列表通过关联作业展示排队、运行、成功、失败、取消状态；旧记录保留既有历史状态。

## 部署与验收

在 backend 执行 `poetry run python manage.py migrate` 应用 consul 0003；执行 `poetry run python manage.py init_system_settings` 导入新增权限，分配角色后重新登录。重启 API、Worker、Beat 并部署前端。新增 Beat 任务 `consul.recover_remote_reads` 每分钟恢复队列和清理过期读取。

验收覆盖 HCL/CTMPL、空文件、不存在、超限/非UTF-8、权限撤销、读取期间编辑、外部改动冲突、正常下发和重载失败恢复。

开发测试使用隔离数据库、模拟 Ansible 事件，以及临时目录和模拟 systemctl 的本地 shell 测试，未操作真实主机或服务，不能替代 Linux 主机及现有 Consul Template 服务单元验收。

本轮完整后端回归1240项通过、6项跳过（39个子测试通过）；最新文件读取、恢复及接口专项122项通过。前端95项契约通过，类型检查、相关 ESLint、生产构建通过。新增接口已纳入67组共享路由契约，列表响应检查扩展到18类。迁移和 OpenAPI 校验通过。
