# 任务系统 HTML 交互原型

入口：同目录 `task-system.html`。单文件，无外部依赖，可直接用浏览器打开。

## 推荐体验路径

1. 流程模板 → Web 应用发布 → 版本 → 草稿 v4 → 编排。
2. 添加步骤 → 从自动化资源选择已发布版本；选择步骤可配置参数、目标参数、超时和失败策略。
3. 保存步骤配置 → 保存草稿 → 校验并发布。
4. 版本列表 → 执行 → 选择主机 → 预览并执行 → 确认模拟执行。
5. 运行详情 → 模拟成功/失败；运行中可取消，失败可重试；查看步骤、主机、日志、快照、参数、审计。
6. 定时计划 → 新建/编辑 → 动态分组或固定主机 → 保存 → 立即触发。
7. 主机资产 → 勾选主机 → 创建任务，体验从资产反向发起执行。

## 页面与按钮

- 任务概览：统计、快捷入口、最近运行。
- 流程模板：搜索、分页、新增、编辑、版本、执行、复制、启停、删除保护。
- 版本抽屉：空白草稿、复制草稿、编排、只读查看、发布、归档、计划引用保护。
- 步骤编排：资源选择、内容预览、选择步骤、上下移动、复制、删除、配置、保存、校验、发布、未保存离开确认。
- 创建任务：固定流程版本、参数 JSON、目标参数、统一主机选择器、Worker 池、超时、预览和目标校验。
- 任务列表/详情：搜索、分页、取消、再次执行、失败重试、结果模拟、日志下载和快照查看。
- 定时计划：新增、编辑、固定主机选择、动态规则、启停、立即触发、删除。
- 联动资源：主机列表、分页、详情；自动化资源分类、内容；只读审计和 CSV 导出。

## 演示边界

- 仅改变当前页面内存中的测试数据，刷新或使用“重置演示数据”会恢复初始状态。
- 不请求业务 API，不执行命令，不发送通知，不连接任何主机。
- 步骤是线性顺序，未提供 BPMN、并行分支、条件分支和拖拽画布。
- 定时计划只展示周期与手动触发，不启动真实定时器；计划表单演示一个目标参数。手动创建任务支持多个步骤目标参数。
- 重试演示创建关联记录并复制失败步骤，不模拟完整恢复调度。
- 状态和日志是测试占位，运行详情中提供“模拟成功/失败”按钮。
- 自动化资源页用于选择与只读查看已预置的内容；本原型重点是任务闭环，不实现资源管理后台。

## 本轮验证

- 内嵌 JavaScript 语法检查通过。
- 10 个页面渲染器、7 类弹窗渲染器检查通过，190 处生成的按钮引用均存在事件处理器（含重复行操作，不代表 190 个独立功能）。
- 浏览器验证：模板新增、编辑、复制和删除；空流程校验；步骤添加、资源内容查看、排序、保存和发布；主机选择；执行预览；模拟失败、重试、取消；计划创建、固定目标选择、暂停和触发；主机分页；资源分类详情。
- 检查桌面编排布局，以及窄屏布局下的导航和核心操作。
