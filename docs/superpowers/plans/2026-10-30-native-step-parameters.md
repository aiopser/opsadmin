# 编排参数按执行类型简化

用户已确认：API 保持结构化 HTTP 执行器，其余执行类型按原生用法。任务单参数只有一份，脚本自动以环境变量读取，Playbook 自动以 extra_vars 读取，不要求额外配置映射。

实施：
1. 用回归测试证明任务参数继承、原生 Ansible 表达式不被平台提前渲染、历史映射保留。
2. 高级配置使用 config.environment / config.extraVars / 既有 config.args；普通映射行编辑器仅留 Jenkins，命名构建参数。
3. 旧 inputMapping 原样保留，存在时通过历史兼容区域查看，不自动转换或删除；保存时保留已有节点配置。
4. 任务单参数去掉一律称 extra_vars 的文案和依赖映射的自动补齐入口，API 页面与 HTTP 执行路径不变。
5. 验证前端回填保存、类型切换、API 配置与旧映射往返；后端变量与执行回归；类型、lint、构建。


完成验证：后端变量及执行契约 87 项通过；前端契约 101 项通过；修改页面 ESLint 与 TypeScript 检查通过。覆盖清空原生参数、旧映射保留、API 节点配置保留、原生 Jinja 和模块自由命令。
