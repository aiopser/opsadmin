# Consul Template 现有文件接管

用户已确认采用主机整文件管理：config/*.hcl 与 template/*.ctmpl，不拆解 HCL template 块，不额外引入复杂发布审批。

## 范围与设计

- 在现有 Consul 模板编辑器提供文件类型、从主机读取、比较差异。读取只进入草稿，保存不写主机；空文件与不存在、读取失败明确区分。
- 复用 CMDB 目标授权、执行池和 Ansible Runner，后台执行有界文件读取。读取权限独立于下发，执行前后复核；正文短期加密存储，过期清除，不写入作业日志或审计。
- 下发前读取并确认差异，服务端绑定主机、路径、模板修订、执行人和远端 SHA256。远端变化、预览过期或模板被修改时拒绝下发。写入采用临时文件、备份和失败恢复，任务结果关联原记录。
- 当前提供单文件读取和确认下发，可分别接管 config 与 template 目录已有文件；批量目录扫描、文件组联合部署不属于本轮。

## 文件与验证

1. `consul/remote_files.py`、模型、迁移、tasks：权限、大小上限、UTF-8、过期、后台任务租约与读取结果。测试先证明缺失、失败、空文件、越权和过期行为。
2. `consul/templates.py`、views/serializers、权限种子：读取、结果、差异接口；下发绑定校验及恢复脚本。测试绑定替换、重复下发和失败恢复。
3. 前端 monitoring API、consul-template 页面：读取到草稿、差异确认，阻止旧响应覆盖新编辑，保留失败时的当前内容；更新共享接口契约。
4. 运行后端专项回归、迁移与 OpenAPI 检查，前端类型、契约、lint 和构建，补充部署验收说明。真实主机读取和下发只在测试环境由用户验收。

## 实施结果

上述四项已实现并通过自动验证。完整后端1240通过、6跳过；最新专项122通过；前端95项契约通过，类型/相关lint/构建通过。部署及真实主机验收见 `docs/integrations/consul-template-file-takeover.md`。没有实际读取或下发用户的远端文件。
