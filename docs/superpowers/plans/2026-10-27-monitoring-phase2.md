# 监控接入第二阶段 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task.

**Goal:** Catalog 跨节点只读浏览、选定 CMDB 主机批量预览接入、目标级定时同步。

**Architecture:** 复用 consul 客户端及 monitoring 目标/同步记录。Catalog 查询不赋予跨 Agent 写权限；批量接入采用短时签名预览证明，锁住连接和资产后复核快照；定时同步复用单目标队列与纳管校验。

**Tech Stack:** Django / DRF / Celery / Vue3 / Element Plus。

**Spec:** 延续 2026-10-27-consul-monitoring-design.md 的纳管边界，本文记录本阶段细化。

## Global Constraints

- 不重新建云账号、凭据、资产；不写部署数据库或真实 Consul。
- 批量最多 200 台，预览签名十分钟内有效并绑定用户；已存在目标保留原配置，数据变化须重新预览。
- 自动同步默认关闭，至少一分钟；执行账号必须仍有效且拥有同步权限。跟随资产地址还要求主机读取权限，资产不存在/停用/无所选 IP 则明确失败。
- 不自动注销、不自动删除、不批量覆写已有目标。仅新增主机 Exporter 目标，不假定已安装 Exporter。
- 复用前端搜索/抽屉/表格样式、动态菜单及权限依赖；保留既有修改。

## Review Focus

- Catalog 名称 URL 编码、指定 DC 查询、节点检查聚合，跨节点实例不可误标成本 Agent 纳管。
- 预览后资产/IP/已有目标变化或其他用户重放会拒绝；重复确认不得重复创建。
- 排队中与定时任务并发时不重复执行，投递失败可诊断。
- 自动执行账号失效或权限撤销不继续外部写入，CMDB 主机失效不注销旧服务。
- 前端预览、关闭、翻页和变更参数时不展示旧响应，不重复确认。

## Tasks

- [x] 1. Catalog 数据中心/服务名/按服务健康实例 API；只读权限及页面，失败测试→实现→验证。
- [x] 2. 目标增加自动同步间隔、地址来源、跟随地址及执行账号；记录增加 manual/batch/automatic 来源。迁移与队列任务、失败/互斥/撤权测试。
- [x] 3. 签名批量预览/确认 API，原子创建与队列投递；验证资产变化、账号重放、预览过期、重复确认及已有目标保留。
- [x] 4. 两步接入抽屉、目标自动同步表单及记录来源；动态权限、契约测试、类型/规范检查。
- [x] 5. 独立复核、后端回归、OpenAPI/迁移检查、部署文档。

## Rulings

本阶段使用目标级定时同步，不新增复杂策略 app 或全量资产选择器；动态分组新资产自动纳管留后续批次。现有目标的注册、注销归属不变。预览不安装软件、不产生外部写入。
