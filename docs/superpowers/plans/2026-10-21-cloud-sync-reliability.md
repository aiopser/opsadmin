# 多云资产同步可靠性完善

本轮采用 writing-plans 工作流，在当前工作区按顺序执行，保留已有未提交改动。

目标：维持 SDK/API 只读采集和人工预览确认，补齐数据库身份、重复投递、时序保护、采集完整性、状态区分、周期同步和失败通知；不接入 Terraform，不修改现有主机列表结构。

## 约定

- 使用可空唯一身份摘要兼容 MySQL/SQLite，人工资产无来源实例 ID 时保持 NULL；保留现有 source_id API 类型。
- 迁移检测存量重复来源身份并中止，输出资产 ID，禁止自动合并或删除。
- 一次读取任一区域失败即不提交该次自动同步；部分入库失败明确标为 partial。未返回资产永不自动删除/停用。
- 记录采集时间、来源区域和完整性；旧快照不能覆盖新观测。
- 周期同步默认关闭，开启后按账号显式授权同步新增/变化资产；账号锁避免重复调度。
- 云实例状态独立于人工资产状态；采集字段缺失不覆盖，显式空外网可清空，非法数值拒绝。
- 失败通知复用现有通知模板、记录及发送重试，不携带凭据。
- 前端沿用 Soybean Admin / Element Plus 默认样式，仅增加相关配置和说明。
